## Por que isso é um "repositório"?

Se é a primeira vez que você ouve esse termo: um **repositório** é uma pasta de projeto guardada no **GitHub**, o site mais usado no mundo por times de tecnologia para armazenar, organizar e trabalhar em conjunto no código de um projeto. Praticamente toda empresa de tecnologia usa GitHub (ou algo parecido) no dia a dia.

Por enquanto este repositório guarda só os materiais das aulas. Mas ao longo do curso — principalmente nas unidades mais avançadas — vocês vão subir aqui o **código dos aplicativos** que forem desenvolvendo, exatamente como um time de desenvolvimento de verdade faz. Ou seja: além de material de aula, este espaço também é um treino real de como o mercado trabalha.
